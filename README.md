# Liquid Player

Музыкальный плеер для Windows в стиле Liquid Glass: своя библиотека локальных файлов,
синхронизированные тексты песен, оформление для каждой песни и плейлисты.

## Возможности

- **Библиотека.** Файлы и целые папки — через диалог или перетаскиванием в окно.
  MP3, FLAC, OGG, WAV, M4A (AAC и Apple Lossless). Теги и встроенные обложки,
  `cover.jpg` из папки альбома, исправление «кракозябр» в старых русских тегах (Windows-1251).
  Песня узнаётся по хешу содержимого — переименование или перенос файла не теряет её настройки.
- **Воспроизведение.** Потоковое декодирование, перемотка, громкость, перемешивание, повтор,
  горячие клавиши (пробел, стрелки, медиаклавиши).
- **Моя музыка.** Поиск и сортировка по дате добавления, названию и длительности.
- **Плейлисты** и **«Недавно прослушанное»** на Главной.
- **Оформление песни.** Своя обложка, свой фон, затемнение и размытие — для каждой песни отдельно.
- **Тексты песен.** Автопоиск на [lrclib.net](https://lrclib.net), LRC и enhanced LRC (пословная подсветка),
  выбор правильного варианта вручную, загрузка `.lrc`, ручная разметка под музыку, сдвиг ±0,1 с.
- **Правка названия, исполнителя и альбома** — только в библиотеке, сами файлы не меняются.

## Стек

- [Tauri 2](https://tauri.app) (Rust): `rodio` + `symphonia` — звук, `lofty` — теги, `rusqlite` — база SQLite,
  `image` — обложки и фоны, `reqwest` — запросы к lrclib.net.
- Интерфейс: React 19 + TypeScript + Vite, стили на чистом CSS.

## Сборка

Нужны [Rust](https://rustup.rs) (toolchain MSVC), Node.js 22 или новее и WebView2 (в Windows 11 уже есть).

```bash
npm install
npm run tauri dev   # запуск в режиме разработки
npm run release     # сборка .exe → %LOCALAPPDATA%\Programs\Liquid Player + ярлыки в «Пуске» и на рабочем столе
```

Если проект лежит в OneDrive, скопируйте `.cargo/config.toml.example` в `.cargo/config.toml`
и укажите папку сборки вне OneDrive.

## Где хранятся данные

`%APPDATA%\com.liquidplayer.desktop` — база `library.db`, обложки и выбранные картинки.
Переменная окружения `LIQUID_PLAYER_DATA_DIR` подменяет эту папку (для тестов или «портативного» режима).

## Приватность

В интернет приложение обращается только к lrclib.net за текстами песен и отправляет туда
лишь название, исполнителя, альбом и длительность песни.

## Устройство проекта

```
src/                  интерфейс (React)
  views/              зоны: Главная, Моя музыка, Плейлисты, Админ-панель
  components/         общие элементы: список песен, ползунки, обложки, текст песни
  player/ library/ lyrics/ playlists/   состояние и действия
src-tauri/src/        Rust
  audio/              воспроизведение
  library/            база, импорт, теги, обложки, оформление
  lyrics/             lrclib.net, разбор LRC, фоновый поиск
  playlists/          плейлисты и история прослушиваний
scripts/install-local.mjs   копирует собранный .exe и создаёт ярлыки
```
